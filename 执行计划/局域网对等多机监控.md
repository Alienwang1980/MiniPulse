# MiniPulse 局域网对等多机监控 — 最终执行计划 v1.4

## 设计原则

### 对等架构
每台 Mac 运行 MiniPulse，既是数据源（HTTP 广播），也是数据消费者（Bonjour 发现邻居并拉取数据）。不区分 client/server。

### 保护形态
**每次新功能开发完成后、提交前，必须回归验证现有功能正常。**
验证方式：
1. 编译通过（xcodebuild build）
2. 启动 app，肉眼检查所有 12 张卡片正常显示数据（CPU/内存/GPU/电源/电池/网络/磁盘/蓝牙/USB/机器信息/CPU进程/内存进程）
3. 确认本机模式下卡片切换、主题切换、拖拽排序均正常

### 端口与发现机制
- 不使用端口扫描，使用 **Bonjour (mDNS)** 自动发现
- 预定义端口列表：`[8765, 8766, 8767, 8768, 8769, 8770]`（最多 6 台机器）
- MiniPulse 启动时遍历列表，绑定第一个可用端口
- Bonjour 注册 `_minipulse._tcp` 到该端口，其他机器通过 Bonjour 自动获知地址和端口
- 整个发现过程：一个 UDP 多播查询包 + 单播回复，无扫描流量

### 单机双实例测试
- 本机跑两个实例时，第二个实例自动分配到备选端口（如 `8766`）
- Bonjour name 追加端口后缀：`mini-8766`
- 两个实例通过 Bonjour 互发现、互拉数据，模拟局域网多机场景

### Phase 2 — 网络层

#### Step 4: 新建 `LANService.swift`

**新建文件：** `Sources/App/LANService.swift`

**职责：** HTTP Server + Bonjour 广播 + Bonjour 发现 + 数据拉取

**端口管理：**
```swift
private let defaultPorts: [UInt16] = [8765, 8766, 8767, 8768, 8769, 8770]

func start() {
    DispatchQueue.main.async {
        guard let port = self.findAvailablePort(from: defaultPorts) else {
            print("[LANService] No available port, disabling broadcast")
            return
        }
        self.startListener(port: port)
        self.startBroadcasting(port: port)
        self.startDiscovery()
    }
}

private func findAvailablePort(from ports: [UInt16]) -> UInt16? {
    for port in ports {
        // 尝试绑定：如果失败则端口被占用
        let sock = Darwin.socket(AF_INET, SOCK_STREAM, 0)
        if sock >= 0 {
            var addr = sockaddr_in()
            addr.sin_family = sa_family_t(AF_INET)
            addr.sin_port = CFSwapInt16HostToBig(port)
            addr.sin_addr.s_addr = INADDR_ANY
            let bindResult = withUnsafePointer(to: &addr) {
                $0.withMemoryRebound(to: sockaddr.self, capacity: 1) {
                    Darwin.bind(sock, $0, socklen_t(MemoryLayout<sockaddr_in>.size))
                }
            }
            Darwin.close(sock)
            if bindResult == 0 {
                return port  // 绑定成功 = 端口可用
            }
        }
    }
    return nil
}
```

**HTTP Server（NWListener）：**
- 监听找到的端口
- `GET /api/v1/snapshot` → 返回 JSON
- `GET /api/v1/ping` → `{"status":"ok"}`
- 所有 handler `do-catch`，解析失败返回 400，内部错误返回 500
- 响应后关闭连接

**Bonjour 广播（NetService）：**
- 注册 `_minipulse._tcp`，name = `\(hostname)-\(port)`（带端口后缀避免冲突）
- port 需 `CFSwapInt16HostToBig(Int16(port))`

**Bonjour 发现（NetServiceBrowser）：**
- 搜索 `_minipulse._tcp`
- 回调 `didFind` → resolve → 获取 hostName 和 port
- HTTP GET `http://\(hostName):\(port)/api/v1/snapshot`
- 收到 JSON 后对比 hostId 排除本机
- 每个远程主机一个 `Task`，新任务 cancel 旧任务
- 5 秒拉取周期，15 秒超时标记 offline

**广播开关：**
- 关闭时：stop NWListener + stop NetService
- 开启时：重新 start
- 发现和拉取不受广播开关影响（只关对外可见）

**启动线程：** 所有 NetService/NetServiceBrowser 操作必须在主线程。

**验证：** 编译通过。打开浏览器访问 `http://localhost:8765/api/v1/snapshot` 看到 JSON。

struct Host: Identifiable, Equatable {

#### Step 7: 新建 `HostManager.swift`

**新建文件：** `Sources/App/HostManager.swift`

```swift
import SwiftUI

@Observable
final class HostManager {
    static let shared = HostManager()

    private(set) var hosts: [Host] = []
    var selectedHostId: String? = nil  // nil = 本机

    var broadcastingEnabled: Bool {
        didSet {
            UserDefaults.standard.set(broadcastingEnabled, forKey: "broadcastingEnabled")
        }
    }

    // 初始化时创建本机 Host
    private init() {
        self.broadcastingEnabled = UserDefaults.standard.object(forKey: "broadcastingEnabled") as? Bool ?? true
        let localId = SystemMonitor.localHostId
        // 本机 Host 在第一次数据就绪时创建
    }

    // 设置本机 Host（由 ContentView 在数据就绪时调用）
    func setLocalHost(name: String, machine: String) {
        guard !hosts.contains(where: { $0.isLocal }) else { return }
        let host = Host(id: SystemMonitor.localHostId,
                        name: name,
                        machineModel: machine,
                        isLocal: true,
                        isOnline: true)
        hosts.insert(host, at: 0)
    }

    // 更新或添加远程主机
    func upsertRemote(from snapshot: RemoteSnapshot, hostname: String?, port: Int) {
        if let idx = hosts.firstIndex(where: { $0.id == snapshot.hostId }) {
            hosts[idx].name = snapshot.hostname
            hosts[idx].machineModel = snapshot.machineModel
            hosts[idx].lastSnapshot = snapshot
            hosts[idx].lastSeen = Date()
            hosts[idx].isOnline = true
            hosts[idx].serviceHostname = hostname
            hosts[idx].servicePort = port
        } else {
            let host = Host(id: snapshot.hostId,
                            name: snapshot.hostname,
                            machineModel: snapshot.machineModel,
                            isLocal: false,
                            isOnline: true,
                            lastSnapshot: snapshot,
                            lastSeen: Date(),
                            serviceHostname: hostname,
                            servicePort: port)
            hosts.append(host)
        }
    }

    // 标记超时主机为 offline
    func checkTimeouts() {
        let deadline = Date().addingTimeInterval(-15)
        for i in hosts.indices where !hosts[i].isLocal {
            if let lastSeen = hosts[i].lastSeen, lastSeen < deadline {
                hosts[i].isOnline = false
            }
        }
    }

    // 获取选中主机的快照
    var selectedHostSnapshot: RemoteSnapshot? {
        guard let id = selectedHostId else { return nil }
        return hosts.first(where: { $0.id == id })?.lastSnapshot
    }

    // 获取选中主机的可见卡片列表
    func activeCardTypes(for hostId: String) -> [CardType] {
        CardType.allCases.filter { isCardVisible($0, for: hostId) }
    }

    // 卡片可见性
    func isCardVisible(_ cardType: CardType, for hostId: String) -> Bool {
        let key = "hostCardVisibility_\(hostId)_\(cardType.rawValue)"
        return UserDefaults.standard.object(forKey: key) as? Bool ?? true
    }

    func setCardVisible(_ visible: Bool, for cardType: CardType, hostId: String) {
        let key = "hostCardVisibility_\(hostId)_\(cardType.rawValue)"
        UserDefaults.standard.set(visible, forKey: key)
    }

    // 忘记主机（清理所有相关 UserDefaults）
    func forgetHost(_ hostId: String) {
        let prefix = "hostCardVisibility_\(hostId)_"
        for key in UserDefaults.standard.dictionaryRepresentation().keys where key.hasPrefix(prefix) {
            UserDefaults.standard.removeObject(forKey: key)
        }
        hosts.removeAll { $0.id == hostId }
    }
}
```

## 单机双实例测试方法

1. 在 Xcode 中 `Cmd+R` 运行第一个实例（主端口 :8765）
2. 再 `Cmd+R`（或从 Xcode 再次 Run）运行第二个实例 → 自动分配 :8766
3. 两个实例的 Bonjour 注册名分别为 `mini-8765` 和 `mini-8766`
4. 等待 ~5 秒，两个实例应互相发现并显示对方数据
5. 关闭其中一个实例 → 另一个 15 秒后标记 offline
6. 重新启动 → 自动恢复
